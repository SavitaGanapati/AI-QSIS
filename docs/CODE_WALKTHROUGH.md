# Public Code Walkthrough

The companion notebook [`AI-QSIS_Public_Code_Walkthrough.ipynb`](../notebooks/AI-QSIS_Public_Code_Walkthrough.ipynb) demonstrates safe, generic Python patterns using synthetic data.

## Demonstrated
- High-level workflow representation
- Tabular data inspection with pandas
- Basic schema and missing-value checks
- Sorting already-computed example scores
- Writing a synthetic review table to Excel

## Deliberately excluded
- Production `.py` modules and original notebooks
- Private data ingestion and browser automation logic
- Proprietary scoring formulas, feature weights and thresholds
- Exact production candidate-selection rules
- Credentials, tokens, private paths and local configuration

**Important:** this notebook is illustrative. Its synthetic values and example operations are not the production AI-QSIS scoring implementation. Workbook column names alone do not reveal how values are calculated.
